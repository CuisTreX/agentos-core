# Changelog

---

## [1.0.0] - 2026-07-06

### Added

- **Core**
  - Workspace Manifest (00): workspace governance, project isolation, directory rules
  - Context Engine (01): layered context architecture, prompt pollution prevention, context budget management
  - Global Memory (02): cross-project memory, reusable knowledge, engineering standards
  - Engineering Principles (03): SSOT, minimal context, deterministic workflow
  - New Project Protocol (04): AI-driven project initialization, template usage, reading order
  - Handoff Protocol (05): deterministic session recovery, state snapshots, decision recording
  - Agent Rules (06): mandatory behavior contract, reading order, forbidden actions

- **Templates**
  - PROJECT_MANIFEST: project identity, tech stack, constraints, dependencies
  - PROJECT_MEMORY: architecture, business logic, open questions, AI notes
  - ENGINEERING_JOURNAL: work log with decisions and reasoning
  - DECISION_LOG: structured decision recording with rationale and alternatives
  - ISSUES: tracked issues, blockers, and resolutions
  - HANDOFF: session state snapshot for cross-session recovery
  - NEXT_SESSION: prioritized instructions for the next session

- **Scripts**
  - create_project.sh: Unix project scaffolding with auto-numbering
  - create_project.bat: Windows project scaffolding with auto-numbering

- **Examples**
  - WebApp: full-stack web application using AgentOS
  - PythonPackage: Python library development with AgentOS
  - CLI: command-line tool development with AgentOS

### Notes

This is the initial release of AgentOS Core. The framework is stable and ready for production use. All documents follow the AgentOS documentation standard: Purpose, Concept, Architecture, Rules, Examples, Common Mistakes, Best Practices, Summary.
