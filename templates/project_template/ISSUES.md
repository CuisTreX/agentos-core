# ISSUES

**Purpose**: Track bugs, feature requests, technical debt items, and blockers.
Each issue has a unique ID, status, priority, and resolution.

---

## Issue Format

\\\markdown
### ISS-001 — Short Title

- **Status**: Open / In Progress / Resolved / Won't Fix
- **Priority**: P0 (critical) / P1 (high) / P2 (medium) / P3 (low)
- **Reported**: YYYY-MM-DD
- **Reported by**: AI / Human
- **Assigned to**: (optional)
- **Resolution**: (if resolved)

### Description
Detailed description of the issue.

### Steps to Reproduce (for bugs)
1. Step one
2. Step two

### Expected Behavior
What should happen.

### Actual Behavior
What actually happens.

### Notes
Implementation notes, related decisions, etc.
